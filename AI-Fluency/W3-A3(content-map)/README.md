# CTA Logic

The Week 1 sitemap establishes one clear visitor action:

> **Book a build call →**

The content map carries this action through every page so that visitors are not given competing next steps.

The pages therefore move through:

**Land → Believe → Trust → Act**

while maintaining one consistent CTA.
