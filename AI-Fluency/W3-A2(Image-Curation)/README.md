# AI Image Curation

A curated collection of AI-generated visuals selected for a modern Computer Science and AI portfolio.

## Objective

The purpose of this activity was to generate, evaluate, and curate AI-generated visuals for use in a professional technical portfolio.

The visuals were reviewed based on:

- Relevance to Computer Science and AI
- Professional appearance
- Minimal and modern design
- Visual clarity
- Suitability for a developer portfolio
- Consistency with a technical aesthetic

## Curated Visuals

### 1. Hero Background — Accepted

**File:** `hero-background-accepted.svg`

**Decision:** ACCEPTED

**Reason:**  
Selected for its minimal technical aesthetic, strong composition, clean visual structure, and suitability as a hero background for a Computer Science and AI portfolio.

### 2. Hero Background — Rejected

**File:** `hero-background-rejected.svg`

**Decision:** REJECTED

**Reason:**  
Rejected because the visual direction did not sufficiently match the desired professional and minimal portfolio aesthetic.

This demonstrates that AI-generated outputs were evaluated critically rather than automatically accepted.

### 3. Backend Icons — Accepted

**File:** `backend-icons-accepted.svg`

**Decision:** ACCEPTED

**Reason:**  
Selected because the visual concept is relevant to backend development, APIs, software engineering, and AI applications.
